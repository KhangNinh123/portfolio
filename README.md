# Trinh Khang Ninh — Portfolio

Personal portfolio for Trinh Khang Ninh, a fullstack web developer specializing in React, Next.js, Node.js, and production web applications.

The site presents selected product work across responsive websites, e-commerce, real-time web applications, and AI-enabled experiences. It also explains the process used to move from product requirements and interface design through development, validation, deployment, and handover.

## Technology

- Next.js 14 and React 18
- JavaScript and TypeScript
- Tailwind CSS and styled-components
- Framer Motion, GSAP, and Lenis
- Responsive images and production metadata through Next.js

## Pages

- `/` — overview and selected work
- `/work` — featured case studies, product process, and complete project list
- `/about` — development background, technical skills, tools, and experience
- `/contact` — services, process, availability, and contact details

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

Use `npm run build` to verify a production build and `npm run lint` to run the project lint rules.
